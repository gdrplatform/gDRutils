# get names of combo base assays

get names of combo base assays

## Usage

``` r
get_combo_base_assay_names(se = NULL, ...)
```

## Arguments

- se:

  SummarizedExperiment or NULL

- ...:

  Additional arguments to pass to `get_combo_assay_names`.

## Value

charvec
