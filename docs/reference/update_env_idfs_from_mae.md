# Update environment identifiers from MAE object identifiers

Update environment identifiers from MAE object identifiers

## Usage

``` r
update_env_idfs_from_mae(mae_idfs)
```

## Arguments

- mae_idfs:

  A list containing MAE identifiers

## Value

`NULL`

## Examples

``` r
update_env_idfs_from_mae(list(get_env_identifiers()))
```
