# get names of combo score assays

get names of combo score assays

## Usage

``` r
get_combo_score_assay_names(se = NULL, ...)
```

## Arguments

- se:

  SummarizedExperiment or NULL

- ...:

  Additional arguments to pass to `get_combo_assay_names`.

## Value

charvec
