# Get identifiers required for downstream analysis.

Get identifiers required for downstream analysis.

## Usage

``` r
get_required_identifiers()
```

## Value

charvec

## Examples

``` r
get_required_identifiers()
#> [1] "duration"      "cellline"      "cellline_name" "drug"         
#> [5] "drug_name"     "masked_tag"    "concentration"
```
